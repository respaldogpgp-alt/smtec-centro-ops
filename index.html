PUBLICACIÓN EN GITHUB PAGES

Pasos para ponerlo en línea

  1. Crea un repositorio público en GitHub, por ejemplo smtec-centro-ops.
  2. Sube únicamente los archivos de la carpeta archivos del ZIP público a la raíz del repositorio. No subas la carpeta privada ni los PDF originales.
  3. Abre Settings → Pages, selecciona Deploy from a branch, rama main, carpeta /(root) y guarda.
  4. Tu web quedará en https://TU-USUARIO.github.io/smtec-centro-ops/, una vez GitHub complete la publicación.
  5. Opcional: para habilitar consultas privadas en línea, crea primero el archivo vault.enc.json con el generador local y sube solo ese archivo cifrado, nunca data_private.js.

Se solicita a los buscadores no indexar esta web; esto no la vuelve privada. Cualquier persona con la dirección podría acceder a la parte pública. Los archivos internos deben permanecer cifrados y una protección de acceso real exige otro servicio.
